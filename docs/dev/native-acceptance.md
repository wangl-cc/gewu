# Native frontend acceptance

Use the [product specification](../spec/interface.md) and the checks below to judge whether the native frontend is ready for everyday use and distribution. Prioritize displaying and copying the right data, keeping state across file operations, responsive navigation, accessible controls and reliable upgrades. The named Swift suites at `9cc7140` supply regression cases. Read an old suite with `git show 9cc7140:app/Tests/<Suite>.swift` or `git show 9cc7140:app/GewuKit/Tests/<Suite>.swift`. The two original workbook fixtures live in `gpui/tests/fixtures/`. An unchecked box needs an observed result.
